# 🍀 로또 번호 추천 앱

제외수를 선택하면, 나머지 번호 중에서만 랜덤으로 로또 번호(6개)를 추첨해 주는 모바일 우선 웹앱입니다.

## 기능

- **제외수 선택**: 1~45 번호판에서 빼고 싶은 번호를 탭해서 제외 (최대 39개, 새로고침해도 유지됨)
- **번호 추첨**: 남은 번호 중에서 1~5게임을 한 번에 추첨
- **균등 난수**: `crypto.getRandomValues` 기반이라 편향 없이 공정하게 추첨
- **실제 로또 공 색상**: 1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록
- **결과 복사**: 추첨 결과를 클립보드로 복사
- **광고 배너 영역**: 상단/하단에 광고 슬롯 내장 (아래 수익화 가이드 참고)

## 실행 방법

별도 빌드 없이 정적 파일만으로 동작합니다.

```bash
# 로컬에서 확인
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

배포는 GitHub Pages, Netlify, Vercel 등 아무 정적 호스팅이면 됩니다.
GitHub Pages 기준: 저장소 **Settings → Pages → Branch: main** 선택하면 끝.

## 광고 수익화 가이드

### 방법 1: 웹으로 배포 + 구글 애드센스 (가장 간단)

1. 앱을 본인 도메인(또는 GitHub Pages)에 배포
2. [Google AdSense](https://adsense.google.com)에 사이트 등록 후 승인 대기 (보통 며칠~몇 주)
3. 승인되면 `index.html`에 있는 애드센스 주석 두 곳을 해제하고,
   `ca-pub-XXXXXXXXXXXXXXXX`(게시자 ID)와 `data-ad-slot`(광고 단위 ID)을 본인 값으로 교체

> 참고: 애드센스 승인에는 어느 정도의 콘텐츠가 필요하므로, 로또 관련 정보 페이지(당첨 확률 안내, 구매 팁 등)를 몇 개 추가하면 승인 확률이 올라갑니다.

### 방법 2: 구글 플레이 앱으로 출시 + 애드몹(AdMob)

앱 형태로 출시하고 싶다면 이 웹앱을 그대로 감싸면 됩니다.

- **TWA (Trusted Web Activity)**: [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap)으로 이 PWA를 안드로이드 앱으로 패키징 → 플레이 스토어 출시. 광고는 웹 페이지의 애드센스가 그대로 노출됩니다.
- **WebView 앱 + AdMob**: 안드로이드 네이티브 프로젝트에서 WebView로 이 앱을 띄우고, 배너 자리에 AdMob 배너 뷰를 네이티브로 배치. 웹 광고보다 단가(eCPM)가 높은 편입니다.

| | 애드센스 (웹) | 애드몹 (앱) |
|---|---|---|
| 난이도 | 쉬움 | 중간 (안드로이드 빌드 필요) |
| 심사 | 사이트 승인 필요 | 플레이 스토어 + AdMob 승인 |
| 수익 단가 | 보통 | 상대적으로 높음 |

## 파일 구성

```
index.html    앱 마크업 + 광고 슬롯 (애드센스 코드 주석 포함)
style.css     스타일 (모바일 우선, 로또 공 색상)
app.js        제외수 관리 / 난수 추첨 로직
manifest.json PWA 매니페스트 (홈 화면 설치 지원)
icon.svg      앱 아이콘
```

## 면책

본 앱의 추천 번호는 순수 무작위 추첨이며 당첨을 보장하지 않습니다. 복권 구매는 기대 수익이 음수인 오락입니다.
