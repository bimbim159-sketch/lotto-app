# 🍀 로또 번호 추천 앱

`제외수_v2.py`의 전략을 그대로 이식한 모바일 우선 웹앱입니다.
당첨 이력을 분석해 **제외수를 자동 선정**하고, **필터 스택을 통과한(=제외 조합을 걸러낸) 조합에서만** 균등 랜덤으로 번호를 추첨합니다.

## 동작 방식 (제외수_v2.py 파이프라인)

1. **당첨 이력 로드**: [smok95/lotto](https://github.com/smok95/lotto) 전 회차 JSON을 받아 localStorage에 캐시 (오프라인이어도 캐시로 동작)
2. **자동 분석**: 핫넘버(최근 16주) · 장기 미출수(15주+) · 이월 후보 · 추천 풀(이유 포함) 산출
3. **제외수 자동 선정**: "과열 후 냉각" 번호 위주로 5~8개. 장기 미출수·최근 4주 출현·추천 풀 번호는 제외수 금지 (가드)
4. **필터 스택**: 총합 100~175 → 홀짝 2:4~4:2 → 고저 2:4~4:2 → AC값 7+ → 동끝수 2개 이하 → 연번 2연속 이하 → 32~45 최소 2개(비인기 필터)
5. **가설 분산 추첨**: 5게임 = 풀3+(고정수 포함·풀 3개 이상) ×3 + 미출포함 ×1 + 자동 ×1
   — 리젝션 샘플링이라 "조건을 만족하는 전체 조합에서 균등 추첨"과 수학적으로 동일합니다.

파이썬 원본과 동일 데이터로 교차 검증했으며, 분석 결과(제외수·미출수·이월수·추천 풀)와 필터 판정이 일치합니다.
(핫넘버 동률 순서만 다를 수 있음 — 파이썬 `Counter`의 동률 순서는 비결정적이라 JS판은 번호 오름차순으로 고정)

## 기능

- **자동 제외수 + 수동 수정**: 자동 선정된 제외수(빨간 표시)를 탭으로 자유롭게 수정. 장기 미출수(파란 점)는 전략 가드로 제외 불가, 최대 8개 제한
- **번호 추첨**: 필터 통과 조합에서 1~5게임 추첨, 게임별 가설 라벨 + 합/AC값 표시
- **추천 풀 보기**: 번호별 선정 이유(핫넘버/이월/반등/미출/이웃수) 표시
- **균등 난수**: `crypto.getRandomValues` 기반이라 편향 없이 공정하게 추첨
- **실제 로또 공 색상**: 1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록
- **결과 복사**: 추첨 결과를 클립보드로 복사
- **오프라인 대비**: 데이터 수신 실패 시 캐시 사용, 캐시도 없으면 수동 모드(필터 스택은 유지)
- **광고 배너 영역**: 상단/하단에 광고 슬롯 내장 (아래 수익화 가이드 참고)

## 실행 방법

별도 빌드 없이 정적 파일만으로 동작합니다.

```bash
# 로컬에서 확인
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

배포는 GitHub Pages, Netlify, Vercel 등 아무 정적 호스팅이면 됩니다.
GitHub Pages 기준: 저장소 **Settings → Pages → Branch: main** 선택하면 끝.

## 광고 수익화 가이드

### 방법 1: 웹으로 배포 + 구글 애드센스 (가장 간단)

1. 앱을 본인 도메인(또는 GitHub Pages)에 배포
2. [Google AdSense](https://adsense.google.com)에 사이트 등록 후 승인 대기 (보통 며칠~몇 주)
3. 승인되면 `index.html`에 있는 애드센스 주석 두 곳을 해제하고,
   `ca-pub-XXXXXXXXXXXXXXXX`(게시자 ID)와 `data-ad-slot`(광고 단위 ID)을 본인 값으로 교체

> 참고: 애드센스 승인에는 어느 정도의 콘텐츠가 필요하므로, 로또 관련 정보 페이지(당첨 확률 안내, 구매 팁 등)를 몇 개 추가하면 승인 확률이 올라갑니다.

### 방법 2: 구글 플레이 앱으로 출시 + 애드몹(AdMob)

앱 형태로 출시하고 싶다면 이 웹앱을 그대로 감싸면 됩니다.

- **TWA (Trusted Web Activity)**: [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap)으로 이 PWA를 안드로이드 앱으로 패키징 → 플레이 스토어 출시. 광고는 웹 페이지의 애드센스가 그대로 노출됩니다.
- **WebView 앱 + AdMob**: 안드로이드 네이티브 프로젝트에서 WebView로 이 앱을 띄우고, 배너 자리에 AdMob 배너 뷰를 네이티브로 배치. 웹 광고보다 단가(eCPM)가 높은 편입니다.

| | 애드센스 (웹) | 애드몹 (앱) |
|---|---|---|
| 난이도 | 쉬움 | 중간 (안드로이드 빌드 필요) |
| 심사 | 사이트 승인 필요 | 플레이 스토어 + AdMob 승인 |
| 수익 단가 | 보통 | 상대적으로 높음 |

## 파일 구성

```
index.html     앱 마크업 + 광고 슬롯 (애드센스 코드 주석 포함)
style.css      스타일 (모바일 우선, 로또 공 색상)
logic.js       제외수_v2.py 이식판: 분석 / 필터 스택 / 게임 생성 (Node에서도 임포트 가능)
app.js         화면 로직: 데이터 로드·캐시, 번호판, 추첨 UI
제외수_v2.py    원본 파이썬 전략 스크립트 (로직 레퍼런스)
manifest.json  PWA 매니페스트 (홈 화면 설치 지원)
icon.svg       앱 아이콘
```

## 면책
